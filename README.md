# IT Support Portfolio & Field Reference

A collection of hands-on IT support labs, troubleshooting notes, scripts, and technical documentation.

This repository covers the practical skills used in entry-level IT Support, Help Desk, and L1 Desktop Support roles. Each section focuses on common tasks, tools, and problems that IT support technicians encounter.

## Project Goals

- Practise common hardware and software troubleshooting tasks.
- Document solutions to common IT support problems.
- Build practical experience with Windows, Linux and networking.
- Learn ticket handling and basic system administration.
- Maintain a collection of useful scripts and troubleshooting procedures.

This repository will be updated as I complete each module and add new labs, notes, and practical exercises.
