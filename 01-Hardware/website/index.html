The Motherboard

The backbone of every computer system

Architecture & Function

The motherboard is the primary printed circuit board that routes power and data between every component in a computer system. Understanding its layout is foundational for every hardware diagnostic workflow.

◆
CPU Socket

Physical and electrical interface for the processor (e.g., Intel LGA 1700, AMD AM5).

◆
DIMM Slots

Dual In-line Memory Module slots for installing RAM. Dual-channel configurations typically use matched pairs.

◆
PCIe Slots

High-speed expansion slots for graphics cards, network cards, and other add-in boards.

◆
SATA & M.2 Connectors

SATA connects 2.5" drives; M.2 slots host high-speed NVMe SSDs directly on the board.

◆
Power Connectors

24-pin ATX (system) and 4/8-pin EPS (CPU) deliver regulated power from the PSU.

◆
Chipset & BIOS/UEFI

Chipset manages I/O; BIOS/UEFI firmware initializes hardware before the operating system loads.

What should an L1 technician verify?
  • Confirm the 24-pin ATX and CPU EPS cables are fully seated.
  • Check that RAM modules are locked into DIMM slots.
  • Verify the CMOS battery (CR2032) is present and holding BIOS settings.
  • Inspect for visible damage: bulging capacitors, discoloration, or debris.
  • Ensure standoffs are properly installed and the board is not shorting against the case.
  • Observe POST behavior and record any beep codes or diagnostic LEDs.

Hardware Components

Core parts every IT technician must know

Processor

Central Processing Unit

The system's primary processor. Executes instructions and manages data flow across all hardware.

  • Cores / ThreadsPhysical / Logical
  • Clock SpeedGHz
  • CacheL1 / L2 / L3
  • SocketLGA / AM
Technical details & troubleshooting

Common symptoms: Random shutdowns under load, thermal throttling, 100% CPU usage freezes, failure to POST.

First-line checks:

  • Verify cooler is mounted and fan is spinning.
  • Monitor temperatures with HWMonitor or similar tools.
  • Review Task Manager / Process Explorer for runaway processes.
  • Inspect CPU socket for bent pins when a board is accessible.
Memory

Random Access Memory

Volatile high-speed memory holding active data for the CPU. All contents are cleared on power loss.

  • GenerationsDDR3 / DDR4 / DDR5
  • Form FactorsDIMM / SO-DIMM
  • SpeedMHz (MT/s)
  • CapacityGB per module
Technical details & troubleshooting

Common symptoms: Blue screens, random freezes, boot failure with no video, continuous beep codes.

First-line checks:

  • Reseat each module firmly until the retention clips click.
  • Boot with a single stick to isolate a failing module.
  • Run Windows Memory Diagnostic (mdsched.exe) or MemTest86.
  • Confirm modules match the motherboard's supported specification.
Storage

HDD · SATA SSD · NVMe

Non-volatile storage retaining the operating system, applications, and user data between sessions.

  • HDD~80–160 MB/s
  • SATA SSD~500–550 MB/s
  • NVMe3,500+ MB/s
  • HealthS.M.A.R.T. metrics
Technical details & troubleshooting

Common symptoms: Boot failures, "Operating System Not Found", slow performance, clicking sounds, file corruption.

First-line checks:

  • Confirm the drive appears in BIOS/UEFI before troubleshooting the OS.
  • Review S.M.A.R.T. health in CrystalDiskInfo or vendor tools.
  • Verify SATA / M.2 connections and swap suspect SATA cables.
  • Back up data immediately if degradation is suspected.
Graphics

Graphics Processing Unit

Dedicated processor for rendering display output and accelerating parallel workloads.

  • VRAMDedicated memory
  • InterfacePCIe x16
  • OutputsHDMI / DP / DVI
  • Power6/8-pin PCIe
Technical details & troubleshooting

Common symptoms: No display, visual artifacts, driver crashes, fan not spinning, system boots without video.

First-line checks:

  • Reseat the card in its PCIe slot.
  • Confirm supplementary PCIe power connectors are attached.
  • Test with integrated graphics (if available) to isolate the GPU.
  • Reinstall drivers using a clean uninstall tool when appropriate.
Power

Power Supply Unit

Converts AC mains power into regulated DC voltages required by every internal component.

  • WattageTotal output (W)
  • Efficiency80 PLUS Rating
  • ModularityFull / Semi / None
  • Main Connectors24-pin + EPS + PCIe
Technical details & troubleshooting

Common symptoms: No power, random shutdowns, burning smell, coil whine, inability to drive high-load components.

First-line checks:

  • Verify the wall outlet and the power cable with a known-good replacement.
  • Confirm the PSU rear switch is in the ON position.
  • Check that 24-pin and EPS connectors are fully seated.
  • Use a PSU tester or perform a controlled paperclip test when safe to do so.

⚠ Never open a PSU enclosure. Internal capacitors can retain lethal voltages.

Thermal

Cooling System

Fans, heatsinks, and airflow management that keep component temperatures within safe operating limits.

  • CPU CoolerAir / AIO Liquid
  • Case FansIntake / Exhaust
  • InterfaceThermal Paste / Pads
  • MonitoringSensors / PWM
Technical details & troubleshooting

Common symptoms: Thermal shutdowns, throttling, loud fan noise, dust buildup, hot chassis.

First-line checks:

  • Clean dust from heatsinks, fans, and intake filters.
  • Verify all fans spin at startup and respond to load.
  • Reapply thermal paste if the CPU runs hot after cleaning.
  • Confirm case airflow follows a sensible intake/exhaust pattern.

Hardware Troubleshooting

Structured, evidence-based L1 diagnostic matrix

Reported Symptom Possible Hardware Area First-Line Checks Escalation Condition
Computer does not power on PSU, power cable, wall outlet, motherboard Test outlet and cable; verify PSU switch; look for standby LEDs on the board. No response after confirmed power and reseating.
System powers on but no display RAM, GPU, monitor, display cable Reseat RAM and GPU; test with another cable or monitor; try integrated graphics. No video output after component isolation.
Noticeably slow performance Storage drive, RAM, thermal throttling Check Task Manager usage; review S.M.A.R.T. health; monitor temperatures. Metrics suggest failing drive or sustained thermal limits.
Random restarts or shutdowns PSU, CPU cooling, RAM, power settings Review Event Viewer; monitor temperatures; test with a known-good PSU if available. Repeated restarts under verified load with no software cause.
Storage drive not detected SATA/M.2 connection, cable, drive, BIOS Verify BIOS detection; reseat cables; test drive in another known-good system. Drive missing from BIOS across multiple ports/systems.
Memory errors or BSOD referencing memory RAM modules, DIMM slot, motherboard Run memory diagnostic; test one stick at a time; swap into alternate slots. Confirmed errors on multiple modules or slots.
Overheating / thermal shutdowns CPU cooler, fans, thermal paste, dust Clean dust; verify fan operation; monitor live temperatures under load. Temperatures remain unsafe after cleaning and reseating cooler.

Standard Troubleshooting Workflow

01

Gather Information

Collect user impact, timeline, recent changes, and specific error messages before touching hardware.

02

Observe Symptoms

Reproduce the issue when possible. Record indicator LEDs, beep codes, sounds, and on-screen output.

03

Verify with Evidence

Use diagnostic tools, event logs, and known-good components to confirm the suspected cause.

04

Document & Escalate

Record findings, resolution steps, and escalate with structured notes when outside L1 scope.

Windows Diagnostic Commands

Essential built-in utilities for hardware investigation

msinfo32

System Information

Opens a complete system summary — manufacturer, BIOS version, installed RAM, processor details, and OS data. Use this first to confirm what you're working with.

dxdiag

DirectX Diagnostic

Reports GPU model, driver version, display output, and sound device status. Useful for display or graphics-related complaints.

devmgmt.msc

Device Manager

Central console for all installed devices. Yellow warning icons indicate driver or hardware recognition problems.

diskmgmt.msc

Disk Management

Shows every detected storage device, partition layout, and drive status. Use it to confirm a drive is recognized by the OS.

resmon

Resource Monitor

Live, detailed view of CPU, memory, disk, and network activity per process. Use it to identify what is consuming system resources.

sfc /scannow

System File Checker

Scans and repairs corrupted Windows system files. Run from an elevated command prompt when the OS behaves unpredictably.
