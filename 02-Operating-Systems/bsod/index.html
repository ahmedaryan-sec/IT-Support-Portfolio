02Wait — what even is a BSOD?

Sixty seconds of context so the checklists below actually make sense.

The kernel panics, politely

When Windows hits an error it physically cannot recover from — a driver corrupting kernel memory, a dead CPU instruction — it halts everything and shows the blue stop screen. It's not sulking; it's protecting your hardware and data from further damage.

What pulls the trigger

In the wild: buggy drivers (#1 culprit by far), failing RAM, overheating or unstable overclocks, dying SSDs, corrupt system files, and occasionally a Windows update gone sideways. The stop code + the .sys filename on screen tell you which.

The universal first-aid

Write down the stop code → unplug anything you just installed → boot into Safe Mode (Shift + Restart → Troubleshoot) → run sfc /scannow + chkdsk C: /f → update drivers. That alone cures most blue screens.

Golden rule: fix the newest change first. Blue screens almost always follow “I just installed / updated / plugged in…” — walk backwards through your own recent changes before blaming Windows.
